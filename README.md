## Commands to start app

1. npm install <!--Install all dependencies-->
2. npx prisma migrate dev --name <!--Applies database migrations-->
3. npm run seed <!--Run seeder files-->
4. npm run dev <!--Start the server with "next dev"-->
5. npx prisma studio <!--Opens database models in browser-->
6. npx prisma generate <!--Generates the Prisma Client-->


## Tech Stack
### Frontend:
 - Framework - Next.js
 - UI Library - RippleUI
 - Styling - Tailwind CSS

### Backend:
 - Authentication - NextAuth.js
 - Database - PostgreSQL
 - Database ORM - Prisma
